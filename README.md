# Experimental Arcade Vehicle Sample Project

Unreal Engine **5.8**.

```sh
git clone --recurse-submodules -j8 https://github.com/vorixo/ExperimentalArcadeVehicleSampleProject.git
```

Open `MyProject.uproject` and press Play. Boulder controls: **WASD**, **mouse**, **Space** to jump.

See the [rolling boulder article](https://vorixo.github.io/devtricks/phys-prediction-use/) for implementation details and references.
